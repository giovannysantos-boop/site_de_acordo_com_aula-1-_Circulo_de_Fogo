# Circulo de Fogo - Projeto front-end

Esse projeto vem a enetender o bom uso de html e css sobre as paginas web e bom uso de programação.

## Oque foi feito 

- criação de estrutura de HTML em pagina
- organização de conteudo em seções 
- `hedar`,`nav`,`main`,`section`,`article` e `table`
- colocamos banner
- fizemos estilização de css
- definimos cores, fontes, espaçamentos e layout visual

## Estrutura do projeto 

- `index.html` - estrutura da pagina
- `style.css` - estilo e layout do site
- `imagem /` - imagens usadas do projeto

## tecnologias usadas utilizadas

- HTML
- CSS
